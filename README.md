Timer App for Terminal

Counts up until an end time. 
Gives a desktop notification. 

Things to know: 
- Stops when laptop is closed/sleeps


Help Page: 

    End time
        as argument `timer HH:MM:SS`
        default end time is 99:59:59

    Arguments
        can be either an end time or a flag atm

    Flags
        -h  help
